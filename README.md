# Foremostleads.com

A premium, performance-driven marketing agency website built with Next.js, Tailwind CSS, and Framer Motion.

## Features
- Fully responsive design matching the mockup precisely.
- GSAP and Framer Motion animations.
- Contact form built with React Hook Form and Zod.
- Smooth scrolling with Lenis.
- Modern App Router architecture.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
